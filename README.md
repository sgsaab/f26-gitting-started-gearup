# Getting Started Gearup

TypeScript sample code with a small function for the 32 Agent to write, as well as Jest tests.

## Prerequisites

- Make sure you have VsCode and Node installed!

## Setup

1. Clone the repository:

   ```bash
   git clone <repository-url>
   cd getting-started-gearup
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

## Scripts

- **Build**: Compile TypeScript to JavaScript.

  ```bash
  npm run build
  ```

- **Run**: Run a specific file.

  ```bash
  node dist/filename.js
  ```

- **Test**: Run unit tests with Jest.
  ```bash
  npm test
  ```
